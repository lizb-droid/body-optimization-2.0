## 2026-11-06 — Rest times, no supersets, glute-focused Lower B, 1RM cycles

Requested by Liz. Previous versions kept as `*.BEFORE-2026-11-06.md` in this folder.

| # | Category | Change | Why |
|---|---|---|---|
| 1 | Pairing | Supersets removed. Only a core move may pair with the exercise before it | Liz prefers regular sets |
| 2 | Unilateral | All reps one side, rest 30s, then the other side | Recovers better, uses more weight |
